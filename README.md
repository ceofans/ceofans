# CEOFans

CEOFans 是上海译宠科技有限公司面向一人公司、独立创业者和小团队开发的 AI 数字员工平台。你可以为数字员工安排任务，在自己的工作环境中运行工具，再回到平台审核成果。[公司官网](https://www.ceofans.com/)
CEOFans 面向 OPC 一人公司、超级个体和小微团队，把 Ai 数字员工、Ai 智能体、Skills 技能与桌面 Ai 连接成可管理的工作闭环。你选择 Ai 数字员工、派发任务并审核成果；员工令牌（token）让兼容的桌面 Ai 在你的工作环境中执行，成果继续沉淀为企业记忆。

## CEOFans Hermes 桌面端

在 Windows 桌面连接自己的模型，使用技能、工作浏览器和扩展应用。比如在「扩展应用 → 免费token」查到一个模型的免费方案，读完官方领取条件，再决定是否开通。[了解 CEOFans 的桌面工作方式](https://www.ceofans.com/)

## 全球免费 Token

查询国内外模型厂商提供的免费额度、试用与优惠，查看是否需要绑卡、有效期和官方申请入口。命令行工具适合快速筛选，Windows 桌面版还支持手动查询已接入厂商的余额。欢迎附上官方来源，指出已经结束或条件有变化的活动。[开源目录工具](https://github.com/ceofans/free-token) · [Windows 桌面版](https://www.ceofans.com/free-token/?utm_source=github&utm_medium=profile)
